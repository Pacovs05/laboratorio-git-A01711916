# Reporte de Comandos de Git

## git status
Muestra el estado actual del proyecto, indicando cuáles archivos están modificados, cuáles están preparados para guardarse y cuáles aún no están rastreados por Git.

## git add
Agrega los cambios de un archivo a la zona de preparación (staging) para incluirlos en el próximo guardado.

## git commit
Guarda permanentemente en el historial local los cambios que previamente se prepararon, acompañados de un mensaje explicativo.

## git push
Sube todos los commits guardados localmente hacia el repositorio remoto en GitHub.

## git pull
Descarga e integra en tu computadora los cambios más recientes que se encuentran en el repositorio remoto.

## git log
Muestra el historial completo con todos los commits que se han realizado en el proyecto.

## git diff
Muestra las diferencias exactas línea por línea entre los archivos actuales y la versión guardada o preparada.

## git restore
Descarta las modificaciones de un archivo que no se ha preparado y lo regresa al estado del último commit, o sirve para recuperar un archivo borrado por accidente.

## git restore --staged
Saca un archivo de la zona de preparación quitándole el efecto del `git add`, pero conservando intacto todo tu trabajo en el archivo.
